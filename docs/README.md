# Knowledge base and planning

- [Zotero Metadata Watch plugin plan](zotero-metadata-watch-plugin-plan.md):
  user-supplied product and architecture proposal, preserved verbatim as a
  planning resource. Its roadmap and requirements describe proposed work, not
  implemented functionality or instructions to execute automatically.

The plan targets Zotero 10+, while the current template manifest declares
`strict_min_version: 6.999` and `strict_max_version: 8.*`. Resolve and test the
intended compatibility before implementation; the plan does not establish
current plugin support.
